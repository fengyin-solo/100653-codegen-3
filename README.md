# 城市供水厂制水运行与供水调度管理平台

面向水厂台账、取水泵组、混凝加药、沉淀池运行、滤池反冲洗、消毒加氯、清水池调蓄、出厂水质检测、供水调度指令、管网压力监测、二次供水泵房、水表抄见、爆管抢修、原水监测、阀门井巡检、药剂领用、设备维护与值班交接的一体化城市供水制水调度工作台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 供水稽查与违规用水处理

该模块不走通用台账的 `EntryRow/runAction`，而是独立领域模型（`src/data/inspection-types.ts`）、
独立存储键 `waterworks-ops:inspection`、业务规则集中在 `src/api/inspection-service.ts`，页面只渲染。
页面：`src/views/inspection/index.vue`（列表 + 许可/车辆 + 申报 + 隐患台账）与
`CaseDetailPanel.vue`（详情面板）。处置结论还同步显示在「供水调度指令」页底部的隐患台账。

判定口径收成一份：

- **一套标准**：同一稽查编号下的所有现场记录按当年统一口径裁定；一队（按管径）与二队（按取水量）
  的自报意见只留痕，违规与否只认统一口径。
- **两队打架**：以先到现场（到场时间最早）那一版的实测数据为准，再套统一标准。
- **取水许可按年核发**：口径给上下限、取水量给年度额度。取水申报的口径或许可取水量超许可范围
  一律不允许保存，退回意见逐项写明超了多少（mm / m³）；只有历史年许可的用户不能按新年申报。
- **私接管路**：违规情形里单列、列表与详情都有橙色「私接管路」标记，一眼可分；无证私接直接违规。
- **处置只认两条路**：`限期整改`（整改天数 ≥1 且写入文书，自动生成文书号）与`移交执法`，
  其他写法直接拒绝；处置只有一份、不可改写。不违规的单走`核查销案`（不进隐患台账）。
- **跨片区越权打回**：右上角切换当前出勤片区；操作人片区与稽查单片区不一致、或稽查车按片区归属
  跨片区出勤，均直接打回。车辆按片区出勤见页内「稽查车出勤」表。
- **老单留存**：历史稽查单（如 `JC-2025-0077`）冻结为「老单留存」，按当年口径展示，不按新标准
  回头改写，也不受理任何改动。
- **隐患台账**：处置出具时自动同步到供水调度隐患台账（同一稽查单只落一条），列表页与详情面板
  的处置结论由同一个 `conclusionText()` 给出，保证一致。
- **取数失败可重试**：页面顶部「演练：下一次取数失败」可模拟取数异常，列表区显示
  「重新加载（重试）」按钮。

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `waterworks-ops:entries` 这一项，或调用 `resetModule(模块)`。
